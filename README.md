# View PDF files

JPedal is a pure Java PDF library to provide Java Developers with the
abilities to work with PDF files directly from Java. JPedal makes a
wide range of PDF processing tasks simple to solve in a few lines of
code.

JPedal includes a fully featured Swing PDF Viewer which can be used as a
standalone application or embedded into your own Java application. There
are three provided examples which demonstrate how to open the Viewer, embed
it inside your own window, and control it from your code.

Learn more about [JPedal](https://www.idrsolutions.com/jpedal/).
